# Web 项目规范

本文件适用于当前目录及其所有子目录，与上级公共规范共同生效。以下路径均相对于 `android-api-diff-web/`。

## 公共组件与复用

- 开发界面前先检查现有组件。相同的基础交互优先复用公共组件；缺少能力时优先扩展现有组件，不在页面中重新实现一套。
- 跨业务、无领域语义的 UI 组件统一放在 `src/components/`，文件名和组件名使用 `M` 前缀与 PascalCase，例如 `MButton`、`MInput`、`MSelect`、`MOption`、`MPopover`、`MPopconfirm`、`MSvg`。
- 页面中的按钮使用 `MButton`，文本、数字和多行输入使用 `MInput`，选择器使用 `MSelect` / `MOption`，弹出层和二次确认优先使用 `MPopover` / `MPopconfirm`。
- 基础组件内部尽量使用 `div`、`span` 等通用标签实现界面效果；需要文本输入等原生能力时使用对应控件。页面仍须复用公共组件，不因使用通用标签而另写重复的控件。
- 公共组件负责通用样式、禁用状态和业务需要的交互；页面只保留业务逻辑、布局及必要的差异样式。
- `M` 前缀仅用于基础组件。包含查询、路由、仓库、版本、缓存等业务语义的组件使用业务名称，例如 `SourceCandidatePopover`、`MinSdkSelect`、`DiffResultList`，内部复用基础组件。
- 与组件绑定的公开类型使用完整组件名前缀，例如 `MSelectValue`。组件和状态模块均显式导入，不通过别名、自动导入或全局注册隐藏依赖。

## 源码依赖边界

- `src/components/` 只依赖 Vue、浏览器 API、通用第三方库、其他基础组件和无业务语义的工具，不依赖 `src/views/`、业务 Store、查询核心或持久化逻辑。
- `src/views/` 负责页面组合和业务交互；共享状态放在 `src/store.ts` 或对应业务状态模块，通用能力放在 `src/utils/`。工具模块不得反向依赖页面。
- 查询、索引、源码模型和解析核心统一来自 `android-api-diff` 公共入口，不在 Web 中复制实现，也不通过相对路径引用该包的内部源码。
- Java / AIDL 解析及常量表达式处理通过现有 Worker 适配层执行，不在页面主线程直接调用解析器。
- 沿用当前目录结构；不要为单个界面改动引入另一套分层目录或重复的组件体系。

## 状态与异步交互

- 涉及多个状态、路由、网络或存储的业务操作集中到有明确名称的函数中，事件处理调用这些函数，避免在模板里展开业务流程。
- `computed` 保持纯计算，不在计算过程中修改其他业务状态或触发网络、路由、存储副作用。
- 异步查询沿用现有任务和取消机制，提交结果前确认任务仍有效，防止旧请求覆盖新结果。关联状态尽量在同一段无 `await` 的代码中提交。
- 不新增相互触发的 watcher 链来驱动业务流程。确需同步路由或适配 DOM、动画、第三方实例时，保持依赖与清理逻辑明确。
- 普通加载按钮使用 `MButton` 的 `loading` 状态。需要允许取消的按钮不能因此禁用，应单独呈现忙碌状态并保留取消事件。

## 样式与标签

- 布局统一使用 Tailwind CSS 的 `class` 写法，不使用 UnoCSS 属性写法；重复的控件样式下沉到公共组件，业务专用样式留在业务组件中。
- Tailwind Preflight 负责基础样式重置，不再引入 `normalize.css`。动态类名使用完整静态字符串，不通过拼接生成 Tailwind 无法扫描的类名。
- 本项目不考虑无障碍适配，禁止使用无障碍相关 API、属性和专用实现，包括 `aria-*`、用于无障碍语义的 `role`、屏幕阅读器专用文案及 `sr-only` 等。不为无障碍目的额外添加焦点管理或键盘导航逻辑。
- 无原生行为要求时优先使用 `div`、`span` 等通用标签实现效果，不为语义化单独引入标签。本项目没有原生标签 ESLint 白名单，不引用其他项目的规则文件。
- 图标按钮按交互需要提供普通 `title` 提示，不添加无障碍专用属性。
- 保留属性、事件和 `v-model` 的正常传递。组件替换后检查禁用行为、事件修饰符和业务需要的输入、快捷键等交互是否仍有效。
- 可取消操作的加载与停止状态需可辨识，不能仅靠颜色表达状态。

## SVG 图标

- 图标资源统一放在 `src/assets/svg/`，通过 `MSvg` 使用，新增前先检查是否已有合适图标。
- SVG 文件根 `<svg>` 必须且只能包含 `viewBox` 属性，不设置 `xmlns`、`fill`、`stroke`、`width`、`height`、`class` 或 `style`。
- `fill`、`stroke`、`stroke-width`、`stroke-linecap`、`stroke-linejoin` 等呈现属性写在内部图形元素上；单色图标使用 `currentColor` 继承组件颜色。
- 多色图标的颜色和透明度同样写在对应内部元素上，不通过根 `<svg>` 统一设置。
- 图标尺寸、交互状态和业务动画由使用处或组件控制；已有 SVG 内置动画可以复用。

## 验证

- 界面和公共组件改动执行 Web 类型检查与构建；业务逻辑改动运行对应的现有测试。
- 从仓库根目录执行 `pnpm -F android-api-diff-web type-check` 和 `pnpm build`；完整的现有测试入口是 `pnpm test`。
- 项目已移除 Playwright 和浏览器测试流水线，不为普通界面改动重新引入该依赖或测试命令。没有实际验证的浏览器交互，不宣称已经通过浏览器测试。
